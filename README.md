# Global change and threats to waterbirds in the Asian flyways

> **Archived research repository** — This project is complete and preserved as a record of the analyses and figures developed for the associated publication.

## Overview

This repository contains R code used to develop analyses and publication-quality figures for an academic research paper on waterbirds in the Asian flyways. The scripts support comparisons involving the Central Asian Flyway (CAF) and the East Asian–Australasian Flyway (EAAF), including waterbird taxonomy and conservation status, publication patterns, and human population density within flyway regions.

## Publication

This repository contains the report and analysis associated with:

**Takekawa, J. Y., Prosser, D. J., Yin, S., Batbayar, N., Kumar, S., & Ma, Z. (2026). Global change and threats to waterbirds in the Asian flyways. _Avian Research_.**

## Repository contents

- `pop_density_under_flyways.R` — compares land area and human population associated with CAF and EAAF countries and produces publication-ready density visualizations.
- `publication_plotting.R` — processes publication records, identifies overlap between flyway regions, and creates annual publication visualizations.
- `waterbirds_in_flyways.R` — filters and enriches waterbird records with taxonomic information and produces comparative figures for flyway composition and IUCN conservation status.

This repository is no longer under active development because this paper has been published.
